# RoboFlame 🔥

An autonomous firefighting robot built with Arduino and Python.

## About

RoboFlame is an autonomous robot that detects fire, moves toward it, and extinguishes it using a water pump.

The project has two parts:
- Arduino: controls sensors, motors, and pump
- Python: manages commands and serial communication

## Features

- Flame detection with three IR sensors (left, front, right)
- Obstacle detection with ultrasonic sensor
- Autonomous movement toward fire
- Servo-controlled water nozzle
- Serial communication between Arduino and Python
- No external Python libraries required
